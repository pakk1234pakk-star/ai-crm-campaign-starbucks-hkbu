# AI-Powered CRM Campaign Design  
**Starbucks × HKBU – “Brewing Balance: From EMO to Wellness”**

COMP4116 Information Systems Management Lab (2026)

This project applies **Generative AI** and structured prompt engineering to design a digital-first CRM campaign for Starbucks Hong Kong at Hong Kong Baptist University during midterm peak season.

---

## Project Overview

The campaign faced two core challenges:

1. **Customer Acquisition** – Convert price-sensitive students (who usually buy $12–25 drinks) into Starbucks Rewards App users by capturing Zero-Party Data.
2. **Customer Retention & AOV** – Increase purchase frequency and average order value of existing Green/Gold members, especially evening part-time students.

The entire campaign was designed to be driven by the Starbucks Rewards HK App as the central information system.

---

## What I Built

| Component | Description |
|---------|-------------|
| **CO-STAR Prompt Skill** | Reusable enterprise prompt structure for strategic ideation |
| **7-Day Omnichannel Journey** | Event-driven IF / THEN workflow across App, social media, and booth |
| **CX Crisis Triage Skill** | Custom GenAI skill that turns unstructured customer feedback into a structured sentiment & root-cause matrix |
| **Day 4 Agile Recovery Plan** | App-integrated demand throttling, VIP priority lane, product fix, and evening PT inclusion package |

## How to Use the Skills

1. Copy the content of any skill file.
2. Paste it into a GenAI tool that supports custom instructions / system prompts (e.g. Gemini, ChatGPT Custom GPT, or HKBU GenAI).
3. Provide the raw business request or customer feedback as user input.
4. The skill will force structured, commercially relevant output.
